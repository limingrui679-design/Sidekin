# Support

Sidekin is a source Beta for developers and reviewers. It is not a signed or
notarized consumer release and does not include an uptime or response-time SLA.

## Where to ask

- Reproducible defect: open the GitHub bug form.
- Product idea: open the feature form and explain the user problem first.
- Pet Pack format: read `docs/PET_PACK_SDK.md`, then open a focused issue.
- Vulnerability: use the private process in `SECURITY.md`.

Include the exact Sidekin commit or version, operating system, Node version,
steps, expected result, actual result, and sanitized logs. A small reproduction
is more useful than a screenshot alone.

Do not post API keys, prompts, agent replies, proprietary code, full local paths,
session identifiers, application-data folders, or paid generation responses.
Replace personal workspace names with neutral labels before sharing evidence.

Questions about account billing, API availability, Codex, or Claude Code belong
with the relevant provider. Sidekin can diagnose its adapter and local state but
cannot guarantee or repair an upstream service.
