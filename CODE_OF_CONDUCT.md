# Community code of conduct

Sidekin welcomes careful, constructive participation from people of every
background and experience level.

## Expected behavior

- Discuss ideas and evidence, not personal characteristics.
- Give specific, actionable feedback and assume good intent while verifying
  technical claims.
- Respect privacy, consent, authorship, and visual-asset rights.
- Make space for questions and acknowledge corrections plainly.
- Keep public discussions suitable for a general audience.

Harassment, threats, discriminatory language, sexualized attention, deliberate
misgendering, doxxing, impersonation, spam, and knowingly submitting stolen or
unsafe material are not acceptable.

## Reporting and enforcement

For ordinary conduct concerns, contact the repository owner through the public
profile without posting private evidence in an issue. Use a private GitHub
security advisory only for product vulnerabilities. The maintainer may edit or
remove contributions, lock discussions, or restrict participation when needed
to protect contributors and the project. Enforcement decisions should be
proportionate, documented privately, and avoid unnecessary disclosure.

This code applies to repository issues, pull requests, reviews, discussions,
and other spaces represented as part of Sidekin.
