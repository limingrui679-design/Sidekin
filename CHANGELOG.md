# Changelog

All notable user-visible changes are recorded here. Sidekin uses semantic
versioning while in source Beta; compatibility can still change between minor
versions when the migration path is documented and tested.

## [2.2.0-beta.1] - 2026-08-17

### Added

- Independent Codex and Claude Code lifecycle adapters with concurrent task
  cards, diagnostics, bounded fallback discovery, and stale-task recovery.
- Active-day streaks, temperament, growth journal, meaningful care conditions,
  cooldowns, bounded offline progression, and monotonic five-stage evolution.
- Thirteen lifecycle motions shaped by 20 lineage-specific movement profiles.
- Data-only Pet Pack schema 2, migration, validation, hashing, pack/unpack CLI,
  and tamper, traversal, duplicate, corruption, and size rejection.
- Real Electron E2E capture for the Command Center, floating companion,
  Workshop recovery, and Settings.
- Native macOS and Windows CI package gates, dependency audit, CodeQL, and
  explicit application/archive size budgets.
- Zero-warning linting, malformed-state backup recovery, bounded API and file
  inputs, and all-asset integrity checks on the packaged application.
- Contributor, support, privacy, threat-model, security, and issue-triage docs.
- Packaged third-party runtime notices without changing Sidekin's proprietary
  project license or Pet Pack authors' independent licensing choices.

### Changed

- Replaced the full 1254×1254 PNG checkout with 1,000 transparent 768×768 WebP
  runtime forms, 200 lazy thumbnails, and a SHA-256 provenance manifest.
- Moved accepted full-resolution art, audit sheets, and poster sources to a
  commit-pinned archive snapshot, with `archive/full-png-corpus-v2.1` retained
  as a convenience pointer.
- Rebuilt the English README around one selected hero, eight distinct poster
  themes, the full 200-lineage contact sheet, product proof, and explicit
  platform/privacy boundaries.
- Limited renderer-visible reference files to short-lived opaque tokens.
- Discarded original reference paths and file names after making bounded local
  recovery copies; corrupt jobs and templates no longer block healthy siblings.

### Removed

- Hat, face, and aura decoration slots and their persistent state.
- Git LFS as a requirement for a normal source checkout.

## [2.1.0-beta.1]

- Expanded the catalog to 200 lineages and 1,000 accepted forms.
- Added cross-platform Electron runtime work and evolved the README gallery.

## [2.0.0-beta.2]

- Established the Sidekin name, five-stage lineages, local care loop, Workshop,
  and initial source-Beta verification boundary.
