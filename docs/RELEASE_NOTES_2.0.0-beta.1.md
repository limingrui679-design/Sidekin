# Sidekin 2.0.0-beta.1

This prerelease freezes the first publicly reviewable cross-platform Sidekin 2
source Beta. It binds one TypeScript and Electron runtime to native macOS and
Windows CI packaging while preserving explicit signing and evidence limits.

## Included

- local-first floating companion, care loop, growth, and five-stage evolution;
- bounded Codex lifecycle classification without collecting prompt, response,
  code, reasoning, or tool-output content;
- 100 built-in lineages and 500 audited transparent character forms;
- thirteen named motion states and concurrent-task handling;
- resumable Pet Workshop with user-owned API credentials, raw-result recovery,
  stage replacement, and local cutout reprocessing;
- native macOS and Windows ZIPs, adjacent SHA-256 sidecars, portable package
  reports, and one tracked-source snapshot.

## Trust boundary

The macOS CI archive is ad-hoc signed, not Developer ID signed or notarized.
The Windows CI archive is unsigned. The release is source-Beta evidence, not a
consumer installer, store release, production deployment, external validation,
adoption claim, or author-funded real-API test.

`LICENSE`. Public visibility does not grant reuse or redistribution rights.
