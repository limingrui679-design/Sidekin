# Sidekin 2.2.0-beta.1

Sidekin 2.2 turns the project into a reproducible macOS and Windows source Beta
with live Codex and Claude Code activity, deeper persistent growth, varied
lineage motion, a safer creator format, and a dramatically lighter checkout.

## Highlights

- Two independent agent adapters and concurrent live task cards
- Five-stage monotonic growth with meaningful care, streaks, temperament, and a
  bounded journal
- Thirteen lifecycle motions shaped by 20 lineage movement profiles
- 200 lineages and 1,000 optimized runtime forms with a SHA-256 manifest
- Pet Pack schema 2 and a data-only validate/pack/unpack CLI
- Sandboxed renderers, validated IPC, opaque reference tokens, and explicit
  local-first privacy documentation
- Real Electron E2E capture plus native macOS and Windows CI/package gates

## Upgrade notes

- Existing local state migrates to schema 6. Legacy hat, face, and aura data is
  dropped because decoration slots were intentionally removed.
- Schema-1 custom templates migrate on load; exported schema-2 packs include
  explicit metadata and hashes.
- A normal clone no longer requires Git LFS. Accepted full-resolution source art
  remains recoverable from `archive/full-png-corpus-v2.1`.
- Codex hooks may require review through `/hooks`; Claude and Codex integrations
  can be installed or removed independently.

## Distribution boundary

This is a source Beta, not a signed consumer release. macOS packaging is ad-hoc
signed and not notarized; Windows packaging is unsigned. Verification makes no
paid API request and uses no user key.
