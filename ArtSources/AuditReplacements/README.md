# Audit Replacements

This directory preserves the accepted raw ImageGen outputs created during the
post-production lineage audit. The application continues to consume normalized,
transparent PNG files from `Sources/SidekinApp/Resources/Characters`.

Each accepted replacement raw is also copied into `ArtSources/FiveStage` as the
current reproducible stage source. Earlier versions remain recoverable from Git
history; replacement raws are additive evidence for every later repair pass.
