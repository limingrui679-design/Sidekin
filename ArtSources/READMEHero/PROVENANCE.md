# Dynamic README Hero

`hero-dynamic-source.png` is the project-local master for `docs/readme/hero.jpg`.

The image was produced as an identity-preserving edit of the earlier Sidekin poster with the built-in image-generation tool. The art direction replaces the catalog-like edge lineup with a dense creature-collection ensemble: changed poses, foreground cropping, overlap, foreshortening, flight paths, atmospheric depth, and a centered readable brand lockup.

The prompt explicitly prohibited copying characters, logos, capture devices, icons, or other protected elements from existing monster-collection franchises. The resulting composition uses only Sidekin-specific subjects and brand text.

Run `npm run media` to rebuild the JPEG derivative together with the other README images.
